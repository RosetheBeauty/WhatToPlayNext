# Reflection – What To Play Next

## Decisions

One of the biggest decisions I made during this project was how to display the games. I chose a card grid layout instead of a simple list because it makes the website easier to look through and more organized. I also added categories like RPG, Shooter, Survival, and Cozy so users can filter games instead of scrolling through everything. This was important because I wanted the site to feel simple and not overwhelming.

Another decision I made was the overall design style. I used a dark gaming theme with bright accent colors because it fits the idea of video games and makes the site feel more modern. I also added a light mode option so users can switch if they want something easier on the eyes. I chose these features to make the site more interactive.

I also decided to include images for each game. Even though it took time to find and organize them, I felt like it made the site more interesting and helped users quickly recognize each game.

## What Worked

The part I am most happy with is the game grid layout. It looks clean and makes it easy to browse through all the games. The category filter also worked well and helps users quickly find the type of games they want.

I also like the hover effect on the game cards. When you hover over a game, it slightly moves and zooms, which makes the site feel more interactive. The overall design also came out well because the colors, fonts, and cards all match the gaming theme.

## What I Would Do Differently

If I started over, I would organize my files better from the beginning. I had some issues with image placement because I didn’t set up my folders correctly at first, which caused confusion later.

I would also plan the category system earlier. I added categories while building the site, which made me go back and edit a lot of games. Planning it first would have saved time.

Another thing I would change is the images. Some images are different sizes, which makes some cards look uneven. I would resize all images before adding them so everything looks more consistent.

## What I Learned

I learned how HTML, CSS, and JavaScript work together to build a website. I also learned that organization is very important. Small mistakes like wrong file paths or naming files incorrectly can break parts of a website.

I learned how CSS can make a big difference in how a site looks. Things like layout, colors, and hover effects help make the site feel more complete and professional.

I also learned that building a website takes patience. A lot of things did not work on the first try, especially with images and filtering. I had to test and fix things many times before they worked.

Overall, this project taught me how to build and improve a website step by step instead of trying to make everything perfect right away.
